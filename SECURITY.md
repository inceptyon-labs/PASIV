# Security policy

## Supported versions

Only the latest version on `main` (what `/plugin install pasiv@pasiv` and `pasiv-extras@pasiv` install) gets fixes.

## Reporting a vulnerability

Report privately through GitHub: https://github.com/inceptyon-labs/PASIV/security/advisories/new

Please don't open a public issue for a security problem. Include the affected skill, hook or script, steps to reproduce, and what an attacker could do with it.
